=========================================================== FLUJO DE
ACTUALIZACIÓN DEL PROYECTO LIGA MX
===========================================================

ANTES DE INICIAR EL TORNEO

1.  ligamx.csv

    -   Contiene los partidos utilizados para entrenar el modelo.
    -   Ejemplo:
        -   Temporadas históricas
        -   Jornada 1

2.  partidos_predecir.csv

    -   Contiene únicamente los partidos pendientes.
    -   Ejemplo:
        -   Jornada 2
        -   Jornada 3
        -   …
        -   Jornada 17

3.  Ejecutar: generar_predicciones.py

4.  Se genera: predicciones.csv

===========================================================

CUANDO TERMINA UNA JORNADA (Ejemplo: Jornada 2)

PASO 1 Actualizar ligamx.csv

-   Agregar TODOS los partidos de la Jornada 2 con sus resultados
    oficiales.

------------------------------------------------------------------------

PASO 2 Actualizar partidos_predecir.csv

-   Eliminar TODOS los partidos de la Jornada 2.
-   El archivo debe contener únicamente los partidos pendientes.

Ejemplo:

Antes: J2 J3 … J17

Después: J3 J4 … J17

------------------------------------------------------------------------

PASO 3 Actualizar predicciones.csv

NO modificar:

-   pred_local
-   pred_visitante
-   xg_local
-   xg_visitante
-   prob_local
-   prob_empate
-   prob_visitante
-   momios
-   matriz

ÚNICAMENTE actualizar:

-   resultado_local
-   resultado_visitante

con los resultados oficiales.

------------------------------------------------------------------------

PASO 4

Ejecutar nuevamente:

    generar_predicciones.py

El script hará automáticamente:

-   Entrenar otra vez el modelo usando ligamx.csv.
-   Eliminar del historial las predicciones de los partidos que siguen
    pendientes.
-   Generar nuevas predicciones únicamente para esos partidos.
-   Conservar intactas las predicciones de las jornadas ya jugadas.

===========================================================

REPETIR ESTE PROCEDIMIENTO DESPUÉS DE CADA JORNADA

1.  Actualizar ligamx.csv
2.  Eliminar la jornada de partidos_predecir.csv
3.  Actualizar resultados en predicciones.csv
4.  Ejecutar generar_predicciones.py

===========================================================

REGLA DE ORO

Una predicción NUNCA debe modificarse después de que el partido haya
comenzado.

Solamente pueden cambiar:

-   resultado_local
-   resultado_visitante

Todo lo demás debe permanecer exactamente igual para poder evaluar
correctamente el desempeño del modelo al finalizar el torneo.
